# AirCanvas
### A Multimodal Gesture and Voice-Enabled Interactive Drawing System for Enhanced Smart Classroom Engagement

AirCanvas is a Final Year Project developed at Universiti Utara Malaysia (UUM) that enables users to interact with digital content using hand gestures and voice commands. The system replaces conventional input devices such as a mouse, keyboard, or whiteboard with a touchless interface powered by Computer Vision and Artificial Intelligence.

Designed for smart classroom environments, AirCanvas promotes more interactive, engaging, and accessible learning experiences through multimodal interaction. :contentReference[oaicite:2]{index=2}

---

## Features

- ✨ Real-time hand gesture recognition
- 🎙️ Offline voice command recognition
- ✏️ Touchless drawing and interaction
- 📐 Interactive 2D and 3D visualization
- 🖐️ Adaptive gesture stabilization and smoothing
- 👤 Face tracking and dwell-based interaction
- ♿ Accessibility-focused interaction
- 💾 Session persistence for learning continuity
